# Orkestrator agen

Orkestrator agen milik Kun Chen dijalankan lewat harness, bukan dipasang:

```sh
git clone https://github.com/kunchenguid/firstmate && cd firstmate && claude
```

Catatan ini dipisah dari `README.md` karena `tests/pi-calm.test.sh` (dari hulu)
menolak nama proyek itu muncul di `README.md` dan `home.nix` di luar atribusi
lisensi Calm, demi menjaga ekstensi Calm tetap tanpa ketergantungan.
